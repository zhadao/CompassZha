# 路线图

本项目按「阶段 0 → 阶段 5」推进，每个阶段结束设一个检查点，通过后才进入下一阶段。
复杂功能（AI 检索类）永远排在最后。

## 总览

| 阶段 | 主题 | 状态 |
| --- | --- | --- |
| 0 | 交互原型 | 已完成 |
| 1 | 数据层与本地 git | 已完成 |
| 2 | 编辑器升级与日记日历 | 已完成 |
| 3 | 番茄钟 / 日历 / 仪表盘接真 | 已完成 |
| 4 | 语料库与 AI 对话 | 已完成 |
| 5 | 同步与分发 | 进行中 |

---

## 阶段 0 · 交互原型（已完成）

内存态可交互原型：三栏布局、左侧竖导航、六个分区、卡片化浅色 UI。
不落盘、不联网、重启还原。目的是先把信息架构和交互手感定下来，再动数据层。

## 阶段 1 · 数据层与本地 git（已完成）

- 按 `daily/yyyy/yyyy-mm-dd.md` 自动创建当天文件，已存在不覆盖。
- YAML frontmatter 模板 + 五个固定章节。
- 章节级「手术式写回」（详见 `docs/ARCHITECTURE.md`）。
- 快速录入表单写入 frontmatter；今日清单勾选写回文件。
- 每次保存自动 `git add + commit` 到本地数据仓库（纯本地、不联网、不推送）。

## 阶段 2 · 编辑器升级与日记日历（已完成）

- Markdown 编辑双模式：表单模式与所见即所得模式并存，共享同一份数据。
- 编辑器功能精简：关闭所有工具栏与插入菜单，仅保留静默写作能力。
- 日记日历（迷你月历）：点击日期查看 / 创建日记，右键菜单支持打开、收藏（改名为
  `star-yyyy-mm-dd.md`）、删除。
- 异步命令改造：所有 Tauri 命令改为异步，git 操作移入后台线程，
  子进程加 `CREATE_NO_WINDOW`，消除窗口卡顿与黑框闪烁。

## 阶段 3 · 番茄钟 / 日历 / 仪表盘（已完成）

- **番茄钟**：倒计时（预设 10 / 25 / 40 与自定义时长、任务标题、到点自动记录）与
  正计时（停表即记录）双模式，写入 `## 专注记录` 并累加 `focus_minutes`。
- **日历**：FullCalendar 日 / 周 / 月 / 清单视图，新建 / 编辑 / 拖拽写回当日 `## 日程`。
- **仪表盘**：八项指标卡、近 7 / 30 / 90 天趋势七折线、各板块投入热力图。
- **人生板块**：`life/<板块>/` 文件夹视图，多 Markdown 文件管理。

## 阶段 4 · 语料库与 AI 对话（已完成）

- `corpus/` 作为统一语料库：任何放进去的 Markdown 都是语料，**不分类建文件夹、交叉主题只放一份**，
  主题筛选交给 AI 在检索时完成。
- 本地检索 + 对话式问答，回答**带出处**（引用到具体文件）。
- 检索路线为轻量 RAG：AI 扩词选卡 → 本地关键词打分检索 → 生成回答；
  语料无支撑时明确提示「未得到语料库的充分支撑」后由 AI 直接作答。
- 索引卡（`config.json` 的 `corpus_topics`）是 AI 的检索筛选标签，其关键词并入检索打分。
- 同阶段新增**仪表盘 AI 数据分析**：基于已录入的量化指标做趋势分析与建议，只回答数据类问题。
- API Key 只进系统凭据管理器，绝不写入 `config.json`、绝不入 git。
- 原计划的 SQLite 派生索引**推迟**：当前语料规模下文件扫描足够，保留后续升级
  FTS5 / 向量索引的切换位。

## 阶段 5 · 同步与分发（进行中）

- 私密 GitHub 仓库同步：Markdown 保存后自动提交并推送、PAT 只进系统凭据管理器——**已落地**。
- Windows 安装包（安装向导）、本地快照与同步冲突留副本——**待做**。
